Connect your database

This app stores your logs in Firebase so everyone you add sees the same data. Paste your Firebase config below, it's saved only in this browser, never uploaded anywhere else.

Security note: Firestore's "test mode" (step 2 below) leaves your database open to anyone who has your config, with no login required. That's fine for a private tool between people you trust, but don't paste this config anywhere public. If you want real access control later, Firebase's docs cover adding proper security rules.
  1. Go to console.firebase.google.com → create a project
  2. Build → Firestore Database → Create database → test mode
  3. ⚙️ Project settings → scroll to "Your apps" → click </> → register app
  4. Copy the firebaseConfig object shown and paste it below
