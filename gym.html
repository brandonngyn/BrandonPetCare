Connect your database

This app stores your logs in Firebase so everyone you add sees the same data. Paste your Firebase config below, it's saved only in this browser, never uploaded anywhere else.

Security note: Firestore's "test mode" leaves your database open to anyone who has your config, no login required. Fine for a private tool between people you trust, but don't paste this config anywhere public. Recommended: after connecting, go to Firebase Console → Firestore → Rules and paste this in, which restricts writes to the expected shape instead of leaving it wide open to anything:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/entries/{entryId} { allow read: if true; allow create: if request.resource.data.keys().hasAll(['date','day','user','sets','timestamp']) && request.resource.data.user is string && request.resource.data.user.size() < 40; allow delete: if true; allow update: if false; } match /users/{userId}/bodyweight/{docId} { allow read, write: if true; } match /_ping/{docId} { allow read: if true; } } }
  1. Go to console.firebase.google.com → create a project
  2. Build → Firestore Database → Create database → test mode
  3. ⚙️ Project settings → scroll to "Your apps" → click </> → register app
  4. Copy the firebaseConfig object shown and paste it below
